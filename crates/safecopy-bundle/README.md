# safecopy-bundle

Many small files in one stream.

Sends several small files in one stream, each with its own size and hash, so one bad file never spoils the others.

Uses `safecopy-chunks` and `safecopy-resume`.

**Status:** nothing is built yet. This crate is a placeholder in the
[safecopy](../../README.md) workspace; its API will come in a later change.
