# safecopy

The umbrella crate.

Re-exports every safecopy crate under a short name (`safecopy::names`, `safecopy::folder`, and so on). Depend on it for all of them, or on the one crate you need.

**Status:** nothing is built yet. This crate is a placeholder in the
[safecopy](../../README.md) workspace; its API will come in a later change.
